## البيئات

- **السيرفر الحالي:** Oracle VPS، الموقع https://dental.azoclinic.duckdns.org (Docker خلف Caddy). صفحة تحميل التطبيق: `/download`.
  - يحتوي السيرفر على أشياء غير موجودة في git بعد: طابور رسائل الترحيب بالبريد، ملفات `deploy/vps/`، وبعض تعديلات الإعدادات والقوالب. لذلك يُنشر عليه ملفًا بملف، ولا يُنسخ فرع git فوقه كاملًا.
- **النسخة الأوفلاين:** حزمة ويندوز محمولة تعمل بلا إنترنت. تُنشر كإصدار `offline-build-N` في GitHub Releases. تفاصيلها في [`offline/README.md`](../offline/README.md).
  - تحتوي PHP وMariaDB وCaddy مع HTTPS محلي، حتى تعمل كاميرا QR من الأجهزة، والاسم الثابت `clinic.lan` عبر CoreDNS، و16 عملية PHP متوازية لنحو 500 مستخدم.
  - كل إصدار يُجرَّب تلقائيًا على ويندوز قبل نشره: تسجيل الدخول، HTTPS، الشهادة، وضغط 200 طلب.
- **التطبيقات:** كل تعديل في `flutter_app/` يبني APK وIPA غير موقّع ومثبّت ويندوز، ويُنشر كإصدار `app-build-N`.
- **cPanel القديم (cdclinics.com):** النشر إليه عبر `deploy.yml` متوقف بسبب مفاتيح SSH في أسرار GitHub.

- **صلاحية فحص المختبر (2026-10-12):**

  - الاعتماد لا يمدد المدة.
  - الكود في `app/Support/LabFeeGate.php`.

- **المبلغ المدفوع عند التسجيل (2026-10-11):** يُسجَّل كدفعة علاج لحظة التسجيل.
- **صفحة المختبر في الويب:**
  - مسح باركود التذكرة أو البحث بالاسم، وتسجيل النتيجة.
  - طباعة نتيجة الفحص مع رمز المريض.

## التشغيل والاختبار محليًا

```bash
composer install && npm ci && npm run build
cp .env.example .env && php artisan key:generate
php artisan migrate --seed   # يحتاج MySQL/MariaDB، لا يعمل مع SQLite
php artisan test
```

الدخول الافتراضي في قاعدة جديدة: `admin` / `password`. غيّره فورًا.
