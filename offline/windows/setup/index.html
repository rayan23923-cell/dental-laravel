تجهيز الجهاز لنظام العيادة

مرة واحدة لكل جهاز: نزّل شهادة العيادة وثبّتها، ليعمل النظام عبر HTTPS وتعمل كاميرا مسح QR.

تنزيل شهادة العيادة

أندرويد

  1. نزّل الشهادة من الزر أعلاه.
  2. الإعدادات ← الأمان (أو الأمان والخصوصية) ← إعدادات أمان أخرى ← تثبيت من مساحة التخزين ← شهادة CA.
  3. اختر الملف clinic-ca.crt ووافق.

آيفون وآيباد

  1. افتح هذه الصفحة في Safari ونزّل الشهادة، ثم اختر «سماح».
  2. الإعدادات ← «تم تنزيل ملف التعريف» ← تثبيت.
  3. الإعدادات ← عام ← حول ← إعدادات الثقة بالشهادات ← فعّل الثقة الكاملة للشهادة.

حاسوب ويندوز

  1. نزّل الشهادة وافتحها ← تثبيت الشهادة ← الجهاز المحلي.
  2. اختر «وضع كل الشهادات في المخزن التالي» ← Trusted Root Certification Authorities ← إنهاء.
  3. أعد فتح المتصفح.

بعد التثبيت افتح النظام: https://clinic.lan
